##CounselEase 


A Flutter-based web application designed to facilitate online counseling sessions. This app aims to provide users with an intuitive interface to connect with counselors, schedule sessions, and access resources.

🚀 Features
User Authentication: Secure login and registration functionalities.

Session Scheduling: Allows users to book counseling sessions.

Anonymous Queries: Allows students to ask public queries anonymously.

Manage Report: Counsellor can create reports of each student.

Record Attendance: Counsellor can record attendance of students attending each session and save as pdf.
